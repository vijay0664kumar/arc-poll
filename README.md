# Arc Poll

A decentralized onchain polling application built on Arc Testnet.

## Live Demo

https://euphonious-semolina-470412.netlify.app/

## Features

- Connect wallet
- Create polls with 2–4 options
- One vote per wallet per poll
- Onchain vote recording
- Live vote results
- Creator-controlled poll closing
- Closed polls reject new votes
- Arc Testnet
- Non-custodial

## How It Works

1. Connect your wallet.
2. Create a poll with 2–4 options.
3. Users connect their wallets and vote.
4. Votes are recorded through the smart contract.
5. View live results.
6. The poll creator can close the poll.
